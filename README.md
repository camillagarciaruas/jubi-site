# Política de Privacidade do Jubí

Página pública da política de privacidade do aplicativo Jubí, exigida pela
App Store e pela Google Play.

**Não edite o `index.html` aqui.** Ele é gerado a partir do texto que está
dentro do app, em `app/privacidade.tsx` do repositório principal. Para
atualizar:

```bash
node scripts/gerar-privacidade-web.mjs   # no repositório do app
```

O script já copia o resultado para cá quando esta pasta existe ao lado da
pasta do app. Depois é só commitar e dar push aqui.
